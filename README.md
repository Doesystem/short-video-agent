# short-video-agent

A short video agent built with [@lifetimesoft/agent-sdk](https://www.npmjs.com/package/@lifetimesoft/agent-sdk).

## Setup

```bash
npm install
npm run build
```

## Run

```bash
lifectl ai agent run short-video-agent
```

## Development

```bash
npm run dev     # watch mode
npm test        # run tests
```
